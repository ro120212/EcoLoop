# EcoLoop - Presentation Slides (LaTeX Beamer)

## Overview
This presentation is tailored strictly for the **EcoLoop Campus Platform** developed for **NSS College of Engineering, Palakkad**.

It retains the exact Madrid theme, green palette, and layout while reflecting **100% of the actual features and performance architecture built in the project**:
1. **Circular Marketplace & Component Harvesting** (Granular sub-assembly salvage)
2. **AI Hardware Scanner** (Google Gemini 2.5 Flash Vision Multimodal analysis)
3. **Peer-to-Peer Repair Community** (Diagnostic assistant & collaborative ticket resolution)
4. **Physical Handoff Protocol** (Dynamic QR codes + 4-digit PINs)
5. **Institutional Security** (Strict `@nssce.ac.in` Google OAuth verification)
6. **Performance Engineering** (Sub-millisecond in-memory caching, SWR, and canvas compression)

## Instructions for Overleaf

1. Go to [Overleaf](https://www.overleaf.com/).
2. Click **New Project** $\rightarrow$ **Upload Project**.
3. Select `EcoLoop_Presentation.zip`.
4. Overleaf will automatically detect `main.tex`.
5. Ensure the compiler is set to **pdfLaTeX** (default) or **XeLaTeX**.
6. Click **Recompile**.
